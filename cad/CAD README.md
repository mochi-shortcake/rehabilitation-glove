# CAD

Put source CAD and print-ready files here, for example:

- `finger_module_*.step` and `.stl`
- `drum_*.step` and `.stl`
- print settings notes (material, layer height, orientation)

Record the key dimensions next to each part. From the SC09 datasheet: body 23.2 x 12.5 mm, total height 27.3 mm, output shaft R2.4 with a 20-tooth spline, mounting-ear holes 27 mm apart (2 mm holes). Verify against the physical servo with calipers.
